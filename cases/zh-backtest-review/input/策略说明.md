# 策略说明：小盘价值动量 V3（虚构示例）

- 研究员：（虚构）量化研究组
- 股票池：中证1000 成分股
- 调仓频率：每月最后一个交易日调仓
- 选股：综合得分 = 0.4 × 低 PB 排名 + 0.4 × 12-1 月动量排名 + 0.2 × ROE 同比改善排名，取得分最高的 50 只，等权持有
- 比较基准：中证1000 指数
- 回测区间：2019-01-01 至 2025-12-31
- 计划资金规模：5 亿元人民币
- 回测结果（脚本输出）：年化收益 22.8%，夏普 1.41，最大回撤 -24.6%
- 备注：参数（因子权重、动量窗口、持仓数）在 2019–2025 全样本上调过，最终版本见参数试验记录第 27 组。

> 本案例的策略、脚本和全部数字均为虚构演示，不代表任何真实行情、指数或产品业绩。
