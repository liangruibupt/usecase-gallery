# 回测复核报告模板（团队固定格式）

1. 结论摘要：是否建议进入下一阶段（继续研究 / 修正后重测 / 停止），致命问题列表
2. 策略与回测设定：股票池、调仓、基准、区间、资金规模、成本假设
3. 数据口径检查：未来信息、幸存者偏差、财务数据对齐方式、缺失值处理
4. 收益与风险：年化收益、夏普、最大回撤及持续时间、年度拆解
5. 交易成本敏感性：不同成本假设下的收益、临界成本
6. 换手与容量：换手率、持仓流动性、按计划资金规模的容量估算
7. 集中度与收益来源：行业 / 年份集中度
8. 研究偏差：参数试验次数、样本内外切分、留出期复测计划
9. 待重跑清单：需要研究员在本地重新运行的脚本与参数，及预期要看的输出
10. 附：数据与脚本清单
