# 立项文档：华东门店会员小程序上线项目

- 立项日期：2026-07-01　项目经理：何静
- 项目成员：刘洋（研发负责人）、宋佳（会员运营）、马超（门店运营）、吴芳（财务 BP）
- 背景：华东区门店会员目前靠纸质卡和收银台登记，无法线上积分与复购触达。

## 项目目标（立项原文）

| 编号 | 目标 | 指标与口径 |
|---|---|---|
| G1 | 上线时间 | 2026-09-30 前小程序正式上线（所有覆盖门店可扫码注册） |
| G2 | 预算 | 项目总预算 60 万元（含外包开发、设计、门店物料、推广、服务器） |
| G3 | 门店覆盖 | 上线时覆盖华东区 40 家门店 |
| G4 | 会员注册 | 上线后首月（上线日起 30 天）新注册会员 3 万人，口径：完成手机号验证的真实顾客，不含员工与测试账号 |
| G5 | 稳定性 | 上线首月核心页面崩溃率 < 0.5%，口径：崩溃次数 / 会话数 |
| G6 | 用户满意度 | 上线首月会员问卷满意度 ≥ 4.5 分（5 分制） |

## 关键假设

1. 现有 POS 系统的会员积分接口可以直接复用，无需改造。
2. 支付通道资质审核按以往经验 1 周内完成。
3. 门店店员会在收银时主动引导顾客注册。
