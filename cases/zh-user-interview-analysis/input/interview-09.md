# 访谈记录：邵宁（区域运营经理，连锁餐饮，管理 18 家门店）

访谈时间：2026-10-22　访谈形式：电话　记录方式：逐字整理（有删减）

访谈者：门店是怎么使用总部的资料的？

邵宁：标准作业流程、新品操作说明、促销方案，总部发下来，店长要传达给员工。

访谈者：门店能及时拿到最新资料吗？

邵宁：经常拿不到。总部更新了新品配方，有的门店还在用上个月的版本，做出来的口味不对，顾客投诉了才发现。

访谈者：店长一般用什么设备看资料？

邵宁：手机。门店没有电脑，店长都是在手机上看，但现在的知识库手机上很难用，PDF 打开要放大半天。

访谈者：你希望怎么接收更新通知？

邵宁：我不想要所有更新都推给我，跟我区域有关的、跟我门店有关的推给我就够了。最好能自己订阅关心的分类，真正重要的再单独提醒。

访谈者：门店之间的权限要分开吗？

邵宁：要。各门店的经营数据不能互相看，但操作流程大家都能看。

访谈者：搜索好用吗？

邵宁：店长搜"新品"能出来几十个结果，不知道哪个是这个月的。

访谈者：你最想改进什么？

邵宁：门店拿到的永远是最新的，而且手机上能看清楚。
