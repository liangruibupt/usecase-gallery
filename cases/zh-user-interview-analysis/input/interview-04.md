# 访谈记录：韩冬（大客户销售总监，工业设备，团队 25 人）

访谈时间：2026-10-15　访谈形式：电话　记录方式：逐字整理（有删减）

访谈者：你在工作中什么时候最需要查资料？

韩冬：在客户那边。拜访的时候客户突然问一个参数或者一个案例，我得马上在手机上找出来。

访谈者：现在手机上能找到吗？

韩冬：很难。我们的知识库手机上打开是电脑版页面，字很小，表格要左右拖，基本没法用。我一般提前把要用的东西存到手机相册里。

访谈者：资料的准确性有出过问题吗？

韩冬：有一次很严重。两个销售给同一个客户报了不同的折扣，一个是按 8.5 折的老口径，一个是按新的阶梯折扣，因为折扣政策文件有两份，都在知识库里，都没写哪份作废了。客户拿着两个报价来压价，我们很被动。

访谈者：你们有用模板来写文档吗？

韩冬：模板我不太喜欢。销售写拜访记录如果要填十几个字段，他们就不写了。能让我随手记就行，格式以后再说。

访谈者：如果有一个新功能，你最想要什么？

韩冬：手机上能搜、能看、能直接转发给客户，而且转发出去的一定是最新版。
