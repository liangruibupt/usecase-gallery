# 访谈记录：罗志明（销售运营经理，SaaS 公司，团队 45 人）

访谈时间：2026-10-13　访谈形式：线下　记录方式：逐字整理（有删减）

访谈者：你们团队的知识库里主要放什么？

罗志明：报价单、产品手册、竞品对比、合同模板。销售每天都要用。

访谈者：销售一般怎么找资料？

罗志明：基本靠问。在群里喊一声"谁有最新的报价单"，总有人甩一个过来，但甩过来的不一定是最新的。知识库里的搜索他们不用，因为搜出来的结果太多，排序也看不懂。

访谈者：你们怎么通知大家资料更新了？

罗志明：群里发，但群消息一天几百条，很快就被刷下去了。我希望重要更新能直接弹窗，强制每个人点"已读"，全员都推，谁没看我能查到。

访谈者：版本这块有遇到过问题吗？

罗志明：有。产品手册里的功能列表，市场部改了一版，销售手上还是旧的，给客户演示的时候说了一个已经下线的功能，客户当场就问了。

访谈者：你觉得 AI 能帮上忙吗？

罗志明：我不太确定。如果能直接问"某某客户适用哪个报价方案"然后告诉我出处，那挺好；但它要是瞎编，销售拿去用就麻烦了。

访谈者：还有别的想补充吗？

罗志明：资料多不是问题，问题是不知道哪份是对的。
