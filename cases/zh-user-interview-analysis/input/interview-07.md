# 访谈记录：彭飞（创业公司 CTO，团队 8 人）

访谈时间：2026-10-20　访谈形式：视频　记录方式：逐字整理（有删减）

访谈者：你们团队规模不大，为什么会考虑知识库工具？

彭飞：技术文档和产品文档越来越多，大家都存在自己电脑上，新人来了什么都找不到。

访谈者：现在怎么找资料？

彭飞：靠记忆。谁写的就问谁。人一多就不行了，上个月有个同事离职，他负责的接口文档就没人知道放在哪儿。

访谈者：你对权限管理有什么要求？

彭飞：我们就八个人，不需要权限。所有人都能看所有东西，越简单越好，设权限反而会拖慢大家。

访谈者：模板呢？

彭飞：别给我们强制模板。工程师写文档本来就不情愿，再要求填一堆字段，就更没人写了。

访谈者：搜索方面有什么期待？

彭飞：能搜到正文，最好能搜代码片段。现在的工具基本只搜标题。

访谈者：你担心工具本身的维护成本吗？

彭飞：担心。我们没有专门的人维护知识库，如果它需要有人天天整理目录、打标签，那最后一定会荒废。

访谈者：最后一个问题，你理想中的工具是什么样？

彭飞：轻、快、能搜，不需要维护。
