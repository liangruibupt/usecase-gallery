# 访谈记录：苏晴（行政主管，互联网公司，员工 200 人）

访谈时间：2026-10-16　访谈形式：线下　记录方式：逐字整理（有删减）

访谈者：行政在知识库里负责哪些内容？

苏晴：行政制度、办公指南、差旅和报销说明，还有新员工入职指引。

访谈者：员工一般怎么找这些内容？

苏晴：大部分人不找，直接来问我们。一个问题我一周能被问十几遍，比如会议室怎么订、快递寄哪里。

访谈者：为什么他们不去知识库里搜？

苏晴：搜不到。知识库按制度名字建的，员工不会搜《差旅费管理办法》，他搜"高铁能不能坐一等座"，这当然搜不出来。

访谈者：内容更新这块呢？

苏晴：差旅标准今年改过一次，我们更新了文件，但是知识库里有三个地方引用了旧标准，我们只改了一个地方，另外两个还挂着旧的，员工按旧标准报销被财务退回来，又来找我们。

访谈者：新员工入职的时候，知识库能帮上忙吗？

苏晴：理论上可以，但新人第一周看到那么多文件夹会懵。我们希望有一个入职路线，第一天看什么、第一周看什么。

访谈者：如果要迁移到新工具，你怎么看？

苏晴：可以接受，但希望能批量导入，保留原来的目录结构，不然光整理就要一个月。

访谈者：还有什么补充吗？

苏晴：最好员工问的那些问题，知识库能直接给答案，不用再来问我们。
