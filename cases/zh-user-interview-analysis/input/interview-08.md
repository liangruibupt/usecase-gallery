# 访谈记录：任佳（质量管理部经理，医疗器械，团队 40 人）

访谈时间：2026-10-21　访谈形式：线下　记录方式：逐字整理（有删减）

访谈者：质量部门对知识库的要求有什么特别的？

任佳：我们的文件必须受控。作业指导书、检验规程都有版本号，每次修改都要审批，外审的时候要能拿出修改记录。

访谈者：现在的工具能满足吗？

任佳：不能。共享盘里只能看到最后修改时间，看不到谁改了什么。外审时我们要手工整理修订记录，很痛苦。现场也出现过车间拿旧版作业指导书操作的情况。

访谈者：文档格式你们怎么统一？

任佳：必须用模板。我们的受控文件有固定格式，编号、版本、生效日期、审批人缺一不可，我支持强制模板。

访谈者：你作为管理者，还希望看到什么？

任佳：我想知道团队里谁在贡献知识、哪些文档长期没人更新、哪些文档被看得最多。现在完全看不到，没法评估知识管理做得怎么样。

访谈者：迁移和维护你怎么看？

任佳：迁移我们能接受，但需要保留历史版本，不然外审时说不清楚。维护方面，如果每个文件都要手工打标签，我们人手不够。

访谈者：还有补充吗？

任佳：可追溯是第一位的，好不好看是其次。
