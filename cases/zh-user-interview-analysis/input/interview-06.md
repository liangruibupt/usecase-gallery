# 访谈记录：曹立（投标经理，建筑工程公司，团队 15 人）

访谈时间：2026-10-19　访谈形式：视频　记录方式：逐字整理（有删减）

访谈者：投标工作和知识库有什么关系？

曹立：关系很大。资质证书、业绩证明、人员证书、标准方案都在里面，每次投标都要从里面拿。

访谈者：最怕出什么问题？

曹立：最怕发错文件。去年有一次我们在投标文件里放了一份已经过期的旧资质证书扫描件，新证书其实已经下来了，但新旧两份都在同一个文件夹，名字差不多，同事拿错了。结果那个标被判了废标。

访谈者：现在怎么避免？

曹立：我每次都要人工再核一遍有效期，很花时间。如果系统能自动标出过期的证书就好了。

访谈者：你在什么场景下需要用手机？

曹立：开标现场或者去业主那边答疑的时候，经常要临时调一个文件，手机上打不开，只能打电话让办公室同事发。

访谈者：知识库的通知功能你会用吗？

曹立：不会。所有弹窗我都会关掉，一天几十个通知，根本看不过来。真重要的事你打电话给我。

访谈者：搜索呢？

曹立：搜索只能搜标题，证书里的编号、有效期这些内容搜不到。

访谈者：你最希望改进的是什么？

曹立：版本和有效期。拿出去的东西必须是对的，这是底线。
