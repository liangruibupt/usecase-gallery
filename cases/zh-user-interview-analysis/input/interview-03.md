# 访谈记录：唐悦（HR 经理，连锁零售，总部 60 人）

访谈时间：2026-10-14　访谈形式：视频　记录方式：逐字整理（有删减）

访谈者：HR 这边主要在知识库里维护哪些内容？

唐悦：制度文件、员工手册、入职材料、各种流程说明。门店店长也会来看。

访谈者：制度文件更新以后怎么处理旧版本？

唐悦：说实话处理得不好。新制度发了，旧的没人删，门店那边经常拿着去年的考勤制度来问问题。我们现在只能在文件名里加日期，但还是有人看错。

访谈者：你们有没有统一的文档格式？

唐悦：我很希望有。每个人写流程说明的方式都不一样，有的写得很长，有的就三行字。我希望有强制模板，标题、适用范围、生效日期、负责人这几项必须填，不填就不能发布。

访谈者：权限这块你们怎么管？

唐悦：薪酬相关的东西只能 HR 内部看，门店只能看制度和流程。现在共享盘的权限是按文件夹设的，经常有人把文件放错文件夹，就被不该看的人看到了，这个风险很大。

访谈者：换工具的话，迁移成本你怎么看？

唐悦：几百份制度文件要重新整理分类，这是很大的工作量。我们 HR 本身就忙，没有人专门做这个。

访谈者：你理想的知识库是什么样？

唐悦：每份制度都有清楚的生效日期，旧版自动标成"已废止"，门店看到的永远是现行版本。
