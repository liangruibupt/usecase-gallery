# 11 月新员工入职培训结业判定核对报告（V2）

## 一、本版变更说明
- **依据**：「直播观看记录」。成都分公司 8 名学员的第 3、4 次课为线上直播参训。
- **新增规则**：观看时长达到课程时长的 80% 算出勤。课程时长 120 分钟，即观看满 96 分钟及以上计 1 次出勤。
- **重算范围**：只重算成都分公司 8 人。其余 44 人的出勤、成绩和结业状态与 V1 完全一致。
- **其他规则**：成绩、补考、结业规则与 V1 相同。

## 二、判定规则
1. 三份数据（签到、考试成绩、补考）和直播观看记录都按**工号**与花名册对应。
2. 出勤次数 = 现场签到次数 + 线上有效出勤次数。到 3 次及以上为合格。出勤不合格的判"出勤不足"。
3. 成绩：每门 60 分及格。没有成绩记录的判"缺考"。
4. 补考：有补考记录的取补考成绩，最高按 60 分计。
5. 结业：出勤合格，且 4 门最终计分全部 ≥ 60。
6. 状态判定顺序：出勤不足 → 缺考 → 成绩不及格 → 结业。
