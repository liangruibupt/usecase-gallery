# 11 月新员工入职培训结业判定核对报告（V1）

## 一、判定规则
1. 三份数据（签到、考试成绩、补考）都按**工号**与花名册对应，不按姓名匹配。
2. 出勤：4 次课到 3 次及以上为合格。出勤不合格的直接判"出勤不足"，不再判定成绩。
3. 成绩：每门 60 分及格。没有成绩记录的记为缺考，状态判"缺考"。
4. 补考：有补考记录的取补考成绩，最高按 60 分计。补考分低于初考的，也按规则取补考分。
5. 结业：出勤合格，且 4 门最终计分全部 ≥ 60。
6. 状态判定顺序：出勤不足 → 缺考 → 成绩不及格 → 结业。
