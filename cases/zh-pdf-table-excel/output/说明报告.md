## 2. 提取口径

### 2.1 版面处理
- **水印**：「演示」「演示数据」「仅供演示」「虚构」形成的独立行整行剔除。混进单元格的水印字（如「仅18.6%」）只删除该字，并逐条记录。
- **其他噪声字符**：「于-3.8%」「于-3.0%」中的「于」不是水印用字，来源不明。两处都出现在负百分比前，按原表数重算后均吻合，所以删除，并逐条记录。
- **断行与错列**：按版面列位置和数值归属还原。T1「连」/「云港」已合并为一行；T1 的「环比增减」归入收入组，依据是重算验证。
- **多层表头**：T1、T3 的两级表头展开为“指标_期间_单位”格式的单行字段，例如“收入_本月_万元”“占比_本期_%”。
- **跨页合并**：T2（第 2–3 页）和 T6（第 2–3 页）先核对序号连续、列结构一致，再合并，并删除续页重复的标题、表头和单位行。T6 另加“来源页码”列，方便回查。

### 2.2 数据类型
- **金额与数量**：去掉千分位，按原表精度保留小数。
- **百分比**：去掉“%”和“+”，写成百分数数值（8.5 表示 8.5%），字段名注明“%”。
- **负数**：一律写成带负号的数值。T7 的流出项按原表保留负号，净额 = 流入 + 流出。
- **日期**：T5 增加“年月”列（如 2026-01），月份原文另列保留。合计行写成“2026-01至2026-09”。在 Excel 中需要日期运算时，可用 DATEVALUE 等函数转换。
- **脚注符号**：从数值中剥离，移到“脚注标记”列，脚注原文放在“脚注内容”列，例如 T2 序号 9 的「*」、T7 的「①」。

### 2.3 空白、0 与不适用
- 原表为 0 的单元格才写 0。本批原表中没有 0 值。
- 原表空白的数值单元格一律留空，不填 0，也不填推算值。同行的“值状态”列说明原因，分三种：
  - **不适用**：例如 T1 新开城市没有上月数据；
  - **待确认**：例如 T4 合肥仓未盘点、宁波仓损耗率待复核；
  - **原表空白**：例如 T1 合计行的环比，因本月与上月合计口径不同，不可比。
- 文本列中的正常空白（如 T2 多数客户的备注）保持空白，不视为缺失。

### 2.4 合计行与修正原则
- **合计行**：原表有合计行的保留，用“行类型”列区分明细、小计和合计，汇总前请先筛选出明细行。原表没有合计行的（T4、T6、T8）不补行。
- **修正原则**：只有当修正值同时满足合计和业务公式时才修改，例如 T1 合肥。复核不一致的（T5 收入合计）保留原值，只做记录。所有修改都有记录编号，工作表中的“修正记录编号”列可以回查附2。
