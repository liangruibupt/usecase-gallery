## 一、项目背景

澄源仪器现有官网于 2021 年上线，目前存在以下问题：

- 页面老旧；
- 手机端显示错位；
- 咨询表单经常收不到提交；
- 市场部缺少可靠的访问数据。

公司计划在六周内完成官网改版。

## 二、项目目标

1. 完成首页和产品页（3 条产品线，共约 12 个产品详情页）的改版设计与开发。
2. 新官网适配电脑端与手机端。
3. 迁移原有内容：公司介绍、新闻（约 80 篇）、案例（约 20 个）、下载中心资料。
4. 配置咨询表单（提交后通知销售邮箱）和网站数据统计。
5. 上线前完成内容验收与功能验收。

## 三、项目范围

### 3.1 包含事项

| 类别 | 范围说明 |
|---|---|
| 设计 | 首页、产品页（3 条产品线及约 12 个产品详情页）的视觉设计，覆盖电脑端与手机端；沿用现有 VI 规范 |
| 开发 | 首页、产品页前端开发（响应式）；内容管理与数据结构；咨询表单；网站数据统计；旧链接跳转 |
| 文案 | 重写首页、产品页、公司介绍文案 |
| 内容迁移 | 公司介绍、新闻（约 80 篇）、案例（约 20 个）、下载中心资料 |
| 内容处理方式 | 新闻、案例沿用原文，只做格式整理 |
| 旧链接处理 | 旧官网产品页链接跳转到新页面（外部渠道大量引用，属必做项） |
| 环境 | 沿用现有云主机；核查域名、备案现状；评估是否新增 CDN |
| 测试与验收 | 功能测试、电脑端与手机端适配测试、内容验收、功能验收 |
| 上线 | 生产环境部署、上线发布、上线后验证 |

### 排期设计说明

1. **展会周规避**：第 5 周（2027-01-04 至 01-08）有行业展会，市场部投入会减少。需要市场部负责人、产品线经理参与的设计与文案确认，统一安排在第 3 周（12/25）前完成。
2. **开发与设计并行**：前端公共框架基于设计初稿先行开发，定稿后再调整，以压缩工期。如果设计定稿与初稿差异较大，存在返工风险。
3. **IT 资源**：前端、后端开发兼有日常运维工作，排期默认可按计划投入。实际可投入比例待 IT 部负责人确认，必要时调整排期。
4. **上线窗口**：最终验收计划在 2027-01-12 完成，因此建议上线日期不早于 2027-01-13，最终以管理层确认为准。

## 八、验收标准总则

### 8.1 内容验收

- 首页、产品页、公司介绍内容与定稿文案一致；
- 约 12 个产品详情页的内容，经对应产品线经理确认；
- 新闻、案例的数量与内容清单一致，原文未改动，格式统一；
- 下载中心资料齐全，文件可正常下载、打开。

### 8.2 功能验收

- 电脑端与手机端显示正常，无错位（浏览器与机型范围待确认）；
- 咨询表单提交成功，销售邮箱能收到通知；
- 旧官网产品页链接均跳转到对应新页面；
- 网站数据统计能正常记录访问数据；
- 品牌名称、Logo 及视觉风格符合现有 VI 规范。

### 8.3 最终确认

- 由市场部负责人书面确认同意上线。
